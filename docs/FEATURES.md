# Что переносится

Состояние на 1.2.39. Формат Pro Tools — 26.4 (сессии старших версий 2024–2025 читаются). Pro Tools при конвертации не запускается.

## Reaper → Pro Tools (`reaper_to_ptx.py`, приложение)

| Что | Как | Ограничения |
|---|---|---|
| Дорожки, items | моно/стерео/5.1 аудиодорожки из шаблона `pool_N`; items другого формата — на доп. дорожки | до 512 дорожек на сессию, больше — несколько сессий `<name> part N` |
| Аудио | Copy (в Audio Files) или Link to source (UMID из bext, том файла) | FLAC/MP3/другая частота → WAV 24 бит в частоте сессии |
| Пропавшие файлы | офлайн-клипы (без тестового тона), Relink-окно с поиском кандидатов | |
| Фейды, кроссфейды, громкость item, клип-гейн | огибающая take VOLENV → огибающая клип-гейна | клип-гейн на обрезанном клипе не проверен |
| Изменённая скорость | Elastic Audio (Polyphonic) | без смены высоты |
| Альтернативные lanes | плейлисты | |
| Папки | Basic Folder / Routing Folder, закрытые папки | вложенные папки сплющиваются |
| Sends, шины, aux | sends на шины, aux с входом-шиной, основной выход, Master Fader | пары A↔B пропускаются |
| Автоматизация | громкость, пан (стерео баланс → L/R), mute, sends, параметры плагинов (PARMENV: по ID параметра, затем по имени) | параметры плагинов — если параметр есть в списке шаблона или в библиотеке `ptx_templates_params` (147 плагинов) |
| Mute/solo/цвет/комментарии дорожек | | |
| Маркеры | маркеры и регионы (→ selection), цвета | |
| Item groups, пустые items с именем | Clip Groups (моно, стерео, 5.1), в т. ч. пустые | |
| Темп | постоянный | карта темпа — только начальный темп и предупреждение |
| Таймкод | fps, старт сессии, формат счётчиков, частота 44.1/48/88.2/96 | |
| Видео | одна видеодорожка (`--no-video` отключает) | |
| Плагины | шаблон слота (встроенный / созданный PT / личная библиотека) → синтез по идентичности (кэш Pro Tools `AAXPlugInCache`, без него — page tables бандлов AAX; бандлы Waves; таблица IDS) → неактивная заглушка | список непереносимого — в комментарии дорожки |
| Настройки плагинов | FabFilter, soothe2, Altiverb, Speakerphone, Oxford (Sonnox), Soundtoys, Waves, Slapper, JUCE-плагины и плагины со стандартными записями AAX | Symphony, Eventide (единицы), UADx не переносятся |

## Pro Tools → Reaper (`ptx_to_reaper.py`, приложение, расширение Reaper)

| Что | Как | Ограничения |
|---|---|---|
| Дорожки, клипы, фейды | | |
| Аудио | ссылки на файлы; поиск по имени в папке сессии, Relink; Standalone — копия в папку проекта | |
| Клип-гейн | постоянный и огибающая (→ take VOLENV) | |
| Альтернативные плейлисты | lanes или отдельные дорожки | |
| Папки, aux, routing folders | папки Reaper; тип — в заметках проекта | |
| Sends, автоматизация | sends (AUXRECV) + огибающие громкости/пана/mute | |
| VCA | группы с VCA lead/follow, фейдер/mute/solo/автоматизация VCA | |
| Скрытые / замороженные / неактивные дорожки | скрытые → SHOWINMIX 0; фильтры skip_hidden/skip_inactive | |
| Маркеры | маркеры, selections → регионы, маркеры дорожек → пустые items, цвета, комментарии → заметки | |
| Clip groups | с аудио → items с GROUP; пустые → пустые items с именем | |
| Темп | постоянный (TEMPO) | карта темпа не читается |
| Таймкод | fps, старт (сдвиг времени в расширении) | |
| Видео | видео-item | |
| Плагины | VST3 (предпочтительно)/VST2/AU с тем же именем, блоки из библиотеки FX | без блока у Reaper — плагин только в заметках, экспорт блока у Reaper (HarvestFX) |
| Настройки плагинов | те же классы, что в обратную сторону, + параметры по именам через vst3host (значения в Гц/мс/дБ — по шкале плагина) или Reaper API | |
| Предупреждения | VST3 не принимает формат дорожки (5.1 и т. п.); плагин установлен как VST3, но Reaper его не сканировал | |

## Где что включается

- Приложение: опции «What to transfer» и Track Data → флаги `--no-*`, `--off`, `--on` (см. `--help` у обоих скриптов).
- Расширение Reaper: File → Import Pro Tools Session… (Preflight, выбор дорожек, Relink, сдвиг времени, Copy/Link).
