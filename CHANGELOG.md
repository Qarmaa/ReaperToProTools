# История версий

Новые записи добавляет `gui/release/release.sh` (версия, дата, заметки). Ранние версии — по сохранённым заметкам выпусков.

## 1.2.46 — 2026-11-08
- Обновления теперь приходят с GitHub (github.com/Qarmaa/ReaperToProTools)
- Автоматизация параметров плагинов сопоставляется по ID параметра: переносятся тысячи кривых, которые раньше терялись (Pro-Q 4, Pro-C 3, Symphony, VisLM2)
- Waves переносятся с настройками и на машинах без шаблона; плагины узнаются по page tables, даже если Pro Tools ещё не сканировал их
- Библиотека параметров для автоматизации Reaper → PT расширена до 147 плагинов

## 1.2.43 — 2026-10-30
- Настройки Soundtoys и Waves переносятся в обе стороны (Waves — с выбором варианта Mono/Stereo)
- Плагины Pro Tools узнаются по кэшу самого Pro Tools — на любой машине с PT
- Автоматизация параметров плагинов Reaper → PT работает для гораздо большего числа плагинов; списки параметров шаблонов больше не перебивают перенесённые настройки
- Предупреждения в заметках дорожек: VST3 не принимает формат дорожки; плагин установлен, но Reaper его не сканировал
- Исправлены: Radiator вместо Little Radiator, имена Waves «… Stereo», защита от зависания Pro Tools на плагинах JUCE

## 1.2.39 — 2026-10-26
- Настройки JUCE-плагинов (Valhalla, SonoBus, ISL и др.) переносятся без шаблона, по состоянию плагина
- Открытие сессии в Reaper больше не зависает на сканировании Audio Units: список обновляется в фоне
- Исправлено распознавание многоканальных плагинов с длинным именем (18ch и т.п.)
- (внутреннее) Конвертер вынесен в отдельный проект ~/ReaperToProTools

## 1.2.37 — 2026-10-20
- Reaper → PT: item groups и именованные пустые items → Clip Groups (моно, стерео, 5.1), огибающие клип-гейна, цвета маркеров, постоянный темп; заглушки для плагинов без шаблона; Scan installed plug-ins
- PT → Reaper: скрытые дорожки, огибающие клип-гейна, цвета и комментарии маркеров, плагины со списком параметров (Slapper ST), постоянный темп
- Расширение: фильтры Hidden/Frozen
